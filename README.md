## 게임 규칙 (Figma Game Board 330:6486 설명 기준)

- 문제: 스테이지 템플릿에서 자동 생성 (보기 3 · 정답 1, 정답 위치와 수치는 판마다 바뀜). Typography = 글자 간격 → 굵기 → 크기 (FIND)
- 문제 유형 제목: FIND '다른 하나를 찾아라!' · MATCH '똑같은 하나를 찾아라!' · PICK '조건에 맞는 하나를 찾아라!' (STAGE 02~05는 미션별 제목, 아래 표)
- 정답 인사이트: STAGE 02~05에서 정답일 때만 피드백 영역에 한 문장 표시 (오답·TIME OVER에는 없음)
- 카드를 누르면 바로 판정 (정답 확인 단계 없음). 판정 전 게임 버튼은 '다음 문제로'(마지막은 '결과 보기') 비활성
- 5초 스피드 게임: 문제가 뜨면 05.0s부터 0.1초 단위 카운트다운, 카드를 누르면 즉시 정지. 2초 이하는 레드
- 시간 초과 = 오답과 같은 처리 ('TIME OVER' 피드백, 미션당 첫 오답만 +5 XP — 오답·시간 초과를 합쳐 한 번). 다시 도전·다음 문제 = 새 5초
- 피드백 중에는 멈춤. 새로고침해도 남은 시간이 이어짐 (마감 시각 저장 — 새로고침으로 시간을 되돌릴 수 없음)
- ← 버튼: 미션 2·3에서는 직전 문제를 맞힌 상태 그대로 다시 보기(다시 채점·XP 없음). 풀던 문제의 타이머는 멈췄다가 '다음 문제로'로 돌아오면 남은 시간부터 이어짐. 미션 1에서는 STAGE SELECT로 이동
- 게임 화면 배치: PC 상단 = 타이머 · 문제 제목 · 진행 바, 레벨·XP는 헤더 (MISSION 배지 삭제) / 모바일 = 제목 → 설명 → 타이머 + 진행 바 → 답안 → 버튼
- 정답 XP: 연속 정답 1·2·3번째에 +30 · +40 · +50 (GREAT / PERFECT 2 COMBO / AMAZING 3 COMBO)
- 오답: 미션마다 처음 한 번만 +5 (TRY AGAIN). 재시도 오답은 0 XP, 배지 숨김. 오답이면 콤보 0
- 오답 뒤 '다시 도전하기' = 같은 미션 재시도. 오답일 때 정답 카드는 공개하지 않음
- 판정 순간 헤더 XP에 더함

## 레벨 규칙 (사용자 지정)

- 100 XP마다 레벨 +1 (LV 01 → LV 05). 표시는 현재 레벨 안의 XP, 예: 누적 125 → LV. 02 · XP 25 / 100
- LV 05가 되면 'XP MAX', 바 가득. 이후 정답을 맞혀도 누적 XP는 400에서 멈춤 (게임 결과의 획득 XP는 그대로 표시)
- 캐릭터는 프로필 외형: 다른 캐릭터로 시작해도 XP·레벨·플레이 기록·업적·닉네임은 그대로 (이전: XP 초기화 → 변경)

## 반응형 규칙

모든 크기 = Figma px × 단위. 비율은 그대로, 단위만 화면에 맞춰 바뀝니다.

| 구간 | 구조 | 단위 |
| --- | --- | --- |
| PC ≥ 1024 | PC 시안 | `--u = clamp(0.533px, min(100vw/1920, (100svh − 헤더)/968), 1.2px)` · 헤더 `--uh = clamp(0.75px, 100vw/1920, 1.2px)` |
| 태블릿 768–1023 | 모바일 시안 구조 | `--c = clamp(1px, min(100vw/700, (100svh − 64)/--ph-t), 1.3px)` |
| 모바일 320–767 | 모바일 시안 | `--c = clamp(0.64px, min(100vw/390, (100svh − 64)/--ph), 1.1px)` — 320×568에서도 모든 페이지가 한 화면 |

- 페이지 기준 높이 `--ph`: 메인 702, 스테이지·결과 733, 게임 776 — 모든 페이지가 스크롤 없이 한 화면
- 헤더는 모든 페이지에서 같은 위치·높이 (PC 112 × 단위, 모바일 64px)
- 화면 밖으로 나가는 장식(글로우·큐브)은 잘라서 가로 스크롤이 생기지 않음
- PC에서 화면이 1920×968 비율보다 세로로 길면(16:10 노트북·모니터 등) 남는 높이를 위·아래 빈 공간이 아니라 요소 사이 간격으로 나눔 (최대 200 × 단위, `--ex`)

## 시안에서 바꾼 부분 (사용자 요청)

- 게임 PC 상단을 한 줄로: 왼쪽 STAGE 정보(로고 정렬선) · 가운데 미션 배지 + 타이틀 · 오른쪽 진행 바(프로필 아이콘 끝 정렬선)
- 게임 PC 답안 카드: 헤더 좌우 정렬선(로고 왼쪽 끝 ~ 프로필 아이콘 오른쪽 끝)에 맞춰 넓힘, 카드 안 요소 약 1.1배
- 정답·오답 피드백(GREAT · PERFECT · AMAZING · TRY AGAIN) 약 1.15배
- 선택한 카드 오른쪽 위 장식 아이콘 삭제 (PC·모바일)
- 게임 PC: 왼쪽 STAGE 정보 대신 헤더의 캐릭터·레벨 정보를 1.5배 카드로 옮김 (게임 화면 PC 헤더에는 알림·프로필만)
- 게임 모바일: STAGE 정보 삭제, 진행 바 가운데. 시안 945px 세로 스크롤 → 한 화면(390×776)으로 세로 간격 압축
- 타이틀 ↔ 설명 간격 = 미션 배지 ↔ 타이틀 간격 (글자 픽셀 기준 측정)
- 메인 모바일 캐러셀: 좌우만 잘라 선택 카드 글로우가 위에서 끊기지 않게 함
- 정답·오답 피드백 캐릭터는 답안 카드 윗선에서 잘라 발이 카드 뒤로 비치지 않게 함

- 모바일은 4페이지 모두 같은 기준 높이(788)를 써서 페이지를 옮겨도 크기가 같고, 마지막 요소(시작 버튼·스테이지 목록·정답 확인·결과 버튼)는 모두 아래 여백 24에 맞춤

## 결과 화면 (개선)

- 순서: 타이틀 → 서브 타이틀 → 정답 수별 보조 메시지 → 캐릭터 + XP 카드 → 결과 카드(3열) → 레벨 XP 카드 → 다시 도전 · 다음 스테이지
- 보조 메시지: 3/3 '완벽해요! 디자인을 보는 눈이 뛰어나네요!' · 2/3 '좋아요! 조금만 더 관찰하면 완벽해요!' · 1/3 '잘했어요! 다시 도전하며 감각을 키워봐요!' · 0/3 '첫 도전을 완료했어요! 다시 한번 도전해 볼까요?'
- 레벨 XP: 헤더와 같은 누적 XP(`eyeq.b.xp`)를 읽기만 함. 레벨업 = 판 시작 XP(`xpStart`, 게임 시작 때 기록)와 지금 레벨 비교 → 'LEVEL UP! LV.01 → LV.02'. 이전 기록(xpStart 없음)은 지금 XP − 획득 XP로 계산
- 다시 도전: 같은 스테이지 새 판(미션 1). 다음 스테이지로: 다음 스테이지 새 판. Composition은 '스테이지 선택으로 →'
- 모바일: 결과 카드도 3열(아이콘 · 라벨 · 숫자), 버튼 두 개 가로 배치(아래 여백 24, 최소 높이 44px). 320px 폭에서는 레벨 XP 숫자가 다음 줄로
- 애니메이션(1회): 타이틀 페이드인, 캐릭터 아래에서 등장, 숫자 카운트업, XP 바 채움, LEVEL UP 배지 강조. 동작 줄이기 설정이면 모두 생략

## 마이페이지

- 진입: PC 헤더 프로필 아이콘 · 모바일 메뉴 My Page (헤더 About 메뉴는 전체 페이지에서 삭제)
- 레벨·XP: 헤더와 같은 값을 읽기만 함 (지급 없음). 칭호는 레벨로 계산: LV.01~03 관찰 새싹 · 04~06 디테일 탐험가 · 07~09 감각 수집가 · 10~14 디자인 탐정 · 15+ EYEQ 마스터
- 통계: 플레이 = 완료 기록 수 · 정답률 = 전체 정답 ÷ 전체 문제 · 최고 콤보 = 기록 중 최댓값 (새로고침·중도 이탈은 기록 안 됨)
- 스테이지별 최고 기록: 정답률 → 콤보 순 (플레이 시간은 저장하지 않음). 행을 누르면 그 스테이지가 선택된 STAGE SELECT로 이동
- 업적 8개: 첫 플레이 · 3연속 정답 · 퍼펙트 클리어 · 5개 스테이지 완료 · 10회 플레이 · 레벨 10 달성 · 50문제 정답 · 100문제 정답. Hover·포커스·탭으로 조건 확인
- 최근 기록 3개(최신순, 3/3이면 PERFECT) · 전체 보기 = 팝업 안에서 스크롤 (페이지 높이 고정)
- PC: 한 화면, 콘텐츠 좌우 = 헤더 정렬선 / 모바일: 1열 세로 스크롤, 단위는 화면 너비 기준. 좁은 화면에서 날짜는 MM.DD HH:mm

### 확인 필요

- 현재 레벨 규칙은 최대 LV.05(누적 400 XP)라서 'LV.07 이상 칭호'와 '레벨 10 달성' 업적은 지금은 얻을 수 없음 (XP 규칙은 바꾸지 않음)
- 한 게임은 3문제라 최고 콤보는 최대 ×3
- 기록 저장 기능 추가 전에 한 플레이는 기록이 없어 통계에 포함되지 않음. 단, 기존 클리어 정보(`eyeq.b.cleared`)는 '첫 플레이' · '5개 스테이지 완료' 업적 판정에 반영

## 최초 닉네임 설정 (메인)

- '이 캐릭터로 시작하기' → 저장된 닉네임이 없으면 팝업(선택한 캐릭터 이미지 · 닉네임 입력 · 0 / 12) → 'EYEQ 시작하기' → STAGE SELECT
- 닉네임이 있으면 팝업 없이 캐릭터만 적용하고 이동. 기록은 있지만 닉네임이 없는 사용자도 팝업으로 닉네임만 설정 (기록 유지)
- 규칙: 최대 12자 · 앞뒤 공백 제거 · 빈 값이면 버튼 비활성(Enter 시 안내). Esc · 닫기 · 바깥 클릭으로 닫힘(저장 안 함)
- 저장값은 마이페이지와 같은 `eyeq.b.nickname` (b-common.js `setNickname`)

## Ranking (사용자 시안 레이아웃)

- 이 브라우저에 저장된 내 완료 기록(`eyeq.b.history`)만 사용 — 다른 사용자 순위나 가짜 데이터 없음. 시안의 '다른 유저' 자리에 내 기록을 성적순으로 표시
- 기간 탭: 주간(최근 7일) / 전체 · 필터: ALL / QUICK PLAY / 5개 스테이지 (새로고침 없이)
- 정렬: 정답률 → 최고 콤보 → 최근 플레이 (3문제·5문제가 섞여도 정답률 기준 · 게임 소요 시간은 저장하지 않으므로 사용 안 함)
- 순위표 아래 고정 행 = 가장 최근에 완료한 기록과 그 순위 (시안의 '내 순위' 자리)
- 오른쪽: 내 최고 기록(현재 기간·필터의 1위 + 다시 도전하기/게임 시작하기) · 나의 게임 기록(획득 XP·정답률·플레이 횟수) · TOP 3 시상대
- 전체 기간 + 스테이지 필터의 1위 = 마이페이지 스테이지별 최고 기록 (같은 `compareRecords`)
- NEW BEST: 게임 완료 시 같은 스테이지(또는 QUICK PLAY)의 이전 최고 기록보다 좋으면 저장(`newBest`)
- PC 한 화면(순위 목록 안에서만 스크롤, 높이 낮은 노트북은 시상대 캐릭터 축소) · 모바일 1열(내 최고 기록 → 게임 기록 → TOP 3 → 순위표, 필터 가로 스크롤)

## QUICK PLAY

- 헤더 오른쪽 작은 CTA 버튼(번개 아이콘). 1366px 미만은 헤더에 자리가 부족해 메뉴(Home · Game · Ranking · Quick Play · My Page) 안으로 이동 — 1024–1365는 메뉴 버튼 표시
- 프로필(캐릭터·닉네임)이 있으면 바로 시작, 없으면 메인 캐릭터 선택 → 최초 닉네임 팝업 → 이어서 QUICK PLAY 시작 (`eyeq.b.next`)
- 문제: `b-questions.js`의 같은 생성·검증 함수로 5개 분야에서 1문제씩 (분야 순서·문제 유형·정답 위치 무작위, 정답 1개 검증). 세션 키 `eyeq.b.stage = "quick"`
- 게임 화면·타이머·판정·XP·콤보는 일반 스테이지와 같은 엔진 (미션 수만 5, 진행 표시 5단계, 제목 위 'QUICK PLAY · 분야'). 최대 콤보 ×5 (XP는 기존 규칙: 3콤보 이상 +50)
- 시작할 때만 READY → 3 → 2 → 1 → GO! (오버레이, 이 동안 선택 불가 · 타이머 대기)
- 결과: 같은 결과 화면에 'QUICK PLAY CLEAR!' · '5가지 디자인 감각에 도전했어요!' · 정답 n / 5 · 5문제 모두 정답이면 PERFECT CLEAR! · 다시 도전 = 새 랜덤 5문제 · 스테이지 선택으로
- 기록: `mode: "quick"`, `total: 5`, 출제 분야 순서(`stages`) 저장. 플레이 횟수·정답률에 포함, 스테이지별 최고 기록·'퍼펙트 클리어(한 스테이지)' 업적에는 섞지 않음
