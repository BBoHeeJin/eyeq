# EYEQ A안 — 전체 페이지

A안과 B안은 서로 독립된 프로젝트입니다. A안은 B안의 파일·스타일·코드를 쓰지 않고, 만드는 방식과 규칙만 같게 적용했습니다. 프레임워크 없이 HTML · CSS · JS로 만들었습니다.
A안 파일은 모두 `a-` 접두어와 `assets/a/` 경로를 씁니다. `index.html`을 더블클릭해서 열어도(로컬 파일) 모두 동작합니다.

- 헤더 메뉴: Home · Level Select · Test · My Result. 모든 페이지 같은 헤더(PC 116 / 모바일 60), 지금 페이지 표시.
- My Result: 오각형 그래프로 만들 예정이라 지금은 누르면 준비 중 팝업이 뜹니다. 테스트 결과 화면은 테스트를 마치면 바로 나옵니다 (헤더는 Test 표시).
- 테스트 중 BASIC↔PRO 토글: 시안의 전환 확인 창(161:1161 · 188:1717)이 뜹니다. 취소하면 그대로 있고, 전환하면 지금 기록을 지우고 다른 모드 첫 문제로 갑니다.
- 진행 상태는 탭 단위로 저장(sessionStorage)되어 새로고침·뒤로 가기에도 유지됩니다. 결과와 모드는 localStorage에 저장됩니다.
- BASIC 정답: Q1 B · Q2 B · Q3 A (결과 시안 기준). 점수 = 정답 수 ÷ 3 × 100 (반올림).
- '다음 문제'는 보기를 고르거나(PRO는 한 번 수정해야) 활성화됩니다. 시안의 Disabled 상태를 따랐습니다.

## Coming Soon 팝업

연결할 화면이 없는 버튼은 누르면 Coming Soon 팝업이 뜹니다. 페이지는 이동하지 않습니다.

- 모든 페이지: My Result, 알림, 마이 프로필 (PC 헤더 · 모바일 헤더 · 모바일 메뉴)
- 메인: 테스트 미리보기, Spacing · Alignment · Hierarchy · Composition 카드 (모바일은 가운데 카드를 누를 때)
- 카테고리: Typography 외 4개 카드
- PRO: 다음 문제 ("PRO 테스트의 다음 문제를 준비하고 있어요.")
- 결과: 해설 보기 ("문제별 해설을 준비하고 있어요.")

## 반응형 규칙 (B안과 같은 방식)

모든 크기는 Figma px × 단위입니다. 비율은 그대로 두고 단위만 화면에 맞춰 바뀝니다.

| 구간 | 구조 | 단위 |
| --- | --- | --- |
| PC ≥ 1024 | PC 시안 | 콘텐츠 `--u = min(100vw/1920, (100svh − 헤더)/964)`, 헤더 `--uh = clamp(0.75px, 100vw/1920, 1.2px)` |
| 태블릿 768–1023 | 모바일 시안 구조 | `--c = clamp(1px, min(100vw/700, (100svh − 60)/700), 1.3px)` |
| 모바일 320–767 | 모바일 시안 | `--c = clamp(0.6px, min(100vw/390, (100svh − 60)/700), 1.1px)` |

- 모바일은 모든 페이지가 같은 기준 높이(700)와 같은 본문 여백(위 16 · 좌우 20 · 아래 24)을 씁니다. 마지막 요소(버튼·카테고리 목록)는 아래 여백에 맞춰 붙여서, 페이지를 옮겨도 크기·여백이 바뀌지 않습니다.
- 모바일 힌트는 한 줄에 들어가도록 짧은 문구를 씁니다 (PC는 원래 문구).
- 가로·세로 중 더 빡빡한 쪽에 맞춰 줄어들어 모든 페이지가 스크롤 없이 한 화면에 들어옵니다.
- PC에서 화면이 세로로 길면 남는 높이를 요소 사이 간격으로 나눕니다 (`--ex`, 최대 200 × 단위).
- 아이콘은 원본 SVG를 HTML에 직접 넣었습니다. 그래서 상태별(Hover·Disabled) 색이 바뀌고 로컬 파일로 열어도 보입니다.

## 결과 화면 조정 (사용자 요청 · 시안과 약간 다름)

- 제목 줄을 다른 페이지와 같은 형식으로 맞춤: 영문 소제목(13) · 제목(36, 강조 파랑) · 설명(16), 같은 위치(y 51)
- 본문은 테스트 화면과 같은 위치(y 212)에서 시작. 점수 카드 → 문제별 결과 → 버튼 순서로 일정한 간격
- 시안의 Inter 한글 표기를 다른 페이지처럼 Noto Sans KR로 통일
- 점수 숫자를 링 가운데에 배치. 모바일에도 작은 링 표시
- 문제 카드: [번호·제목 | 정답/오답 배지] / [선택·정답 | 해설 보기] 두 줄을 양끝 정렬. 오답 배지는 빨강
- 버튼: 다시 테스트하기(연한 파랑) · 다른 감각 테스트(파랑)를 테스트 화면 "다음 문제" 버튼과 같은 위치에 (PC 오른쪽 아래 · 모바일 맨 아래)
- 모바일은 테스트 화면처럼 제목 아래 설명 줄을 생략

## 제안 (Figma에 정의되지 않아 최소한으로 추가)

- Coming Soon 팝업 디자인: A안 시안에 없어 확인 창(161:1164) 스타일을 사용했습니다. 제목은 "아직 준비 중이에요!", 확인 버튼 하나입니다.
- 키보드 포커스 링, Hover·팝업·메뉴 전환 시간 (300ms 내외 ease-out)
- PRO 편집기 숫자 범위: 크기 10–64 · 자간 −2–10 (0.5 단위) · 행간 12–84

## 확인 필요

- **Q2 · Q3는 새로 만든 문제입니다** (시안에는 Q1만 있음). 결과 시안의 주제·정답에 맞췄습니다.
  - Q2 글자 크기: 정보 크기가 모두 같은 포스터(A)와 크기 차이가 있는 포스터(B) 비교, 정답 B
  - Q3 자간 비교: 자연스러운 자간(A)과 너무 넓은 자간(B) 로고 비교, 정답 A
- 결과 문구: 시안에는 2문제 정답(67점) 문구만 있습니다. 3문제 정답과 1문제 이하 정답 문구는 새로 썼습니다.
- PRO 다음 문제와 PRO 결과 화면은 시안에 없어 Coming Soon으로 처리했습니다.
- 모바일 포스터 사진: `poster-photo-mobile.png`가 32×32 빈 이미지로 내려받아져서 PC용 사진을 함께 씁니다.
- PRO 포스터 사진은 원본 파일 자체가 흑백입니다.
- 히어로 카피 폰트는 시안이 Arial인데, 한글이 Arial에 없어 Noto Sans KR로 표시됩니다.
- 로고(EYEQ)는 시안 폰트 'Designer'의 웹 폰트가 없어 SVG 원본을 썼습니다. 내보낸 SVG에 들어 있던 배경 사각형은 지웠습니다.
